# 填批号

把导出表里的批号，按医疗机构逐家填到「辽宁省药品和医用耗材招采管理系统」的待发货列表，勾选后确认发货。

## 输入

1. **表格**：用户提供的导出表路径（扩展名可能是 `.XLS`，实际是 GBK 编码的制表符文本）。
2. **跳过名单**：本次不处理的医疗机构名称（可为空，按包含匹配）。
3. **只填不提交名单**（可选）：只填批号、不勾选也不确认发货的医疗机构，例如规则仍在验证的医院。

没有明确给出跳过名单时，视为空名单——所有医疗机构都处理。

## 环境前提

- Windows；360 安全浏览器已登录招采平台，且停在「按明细发货 → 待发货」页（`.../trade/send-return-message/drug/detail-list?gCode=dTrans`）。
- 可用 `pwsh` 工具和 Python（用 `load_workspace_dependencies` 返回的解释器）。
- 网页控件无法通过 UIA/MSAA 读取，**只能靠截图定位后点击**。本技能自带：

| 脚本 | 用途 |
|---|---|
| `scripts/fillbatch.py` | 解析导出表、按客户/品名查批号 |
| `scripts/browser.ps1` | 窗口截图、前后台、点击、粘贴 |

脚本目录就是本技能的 base directory；下文用 `<技能目录>` 指代它。

## 一、解析表格

```powershell
& $py "<技能目录>\scripts\fillbatch.py" dump "<表格路径>" --json "$env:TEMP\batch.json"
```

输出每家客户的条数。表中关键列：`业务类型`、`开单日期`/`发票日期`、`分公司代码`、`品名`、`型号/规格`、`客户名称`、`商品批号/效期`（含批号/效期/数量）、`生产厂家`。

查单个品名的候选批号（按日期倒序，并提示数量匹配项）：

```powershell
& $py "<技能目录>\scripts\fillbatch.py" lookup "<表格路径>" "<客户名称>" "<品名关键字>" --qty 100
```

## 二、取数规则（必须严格遵守）

- **字段对应**：网页「医疗机构」= 表「客户名称」；网页「通用名」= 表「品名」；网页「发货数量」= 表内数量。
- **取最近日期**那一条的批号。日期列可能叫「发票日期」或「开单日期」（后者带时分秒）：按日期部分比较，同一天取时间更晚的记录。
- **同一天多条**时，取「数量」与网页「发货数量」完全相同的那条；符号也要一致（退货/更正可能是负数）。
- **同名不同包装**（如 `10mg*30T` 与 `10mg*7T*2板`）必须结合网页的「规格/包装」区分，别只看品名。
- 品名可能有别名、括号品牌、`集采` 标记：用包含关系匹配，例如 `达格列净片(安达唐)` 对应 `达格列净片`。
- **网页上已经有批号的行：保留原值，不覆盖**，直接按原值勾选。
- **匹配不到数据**：留空、不勾选，记入最终报告（通常是导出表没覆盖到的新订单）。
- **只填「批号」一列**；「药品有效期至」「发货备注」等一律不填。

## 三、网页操作

所有点击都用屏幕坐标。先取窗口位置：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\scripts\browser.ps1" -Action rect
# rect=left,top,right,bottom size=WxH
```

截图（用 PrintWindow，窗口被遮挡也能截）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\scripts\browser.ps1" -Action capture -Out "$env:TEMP\shot.png"
```

截图像素 `(ix,iy)` 对应屏幕 `(rect.left + ix, rect.top + iy)`。用 Python/PIL 裁剪放大后再看图，确认每个控件的中心坐标；**不要凭记忆硬编码坐标**，页面布局会上下浮动 20–40px。

点击与粘贴：

```powershell
# 点击（会自动置前；被激活吞掉的第一下，可用 -Times 2 补一下）
powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\scripts\browser.ps1" -Action click -X 1362 -Y 566

# 点进输入框并粘贴（推荐：剪贴板 + Ctrl+V，逐字符输入在部分输入框会丢字）
powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\scripts\browser.ps1" -Action paste -X 1362 -Y 566 -Text "261380"
```

### 每家医院的标准动作

1. 「医疗机构」输入框填医院全称 → 点「查询」→ 等到加载结束（转圈消失）。
2. 截图确认结果：若显示「暂无数据」，直接换下一家。
3. 逐行读取「通用名」「规格/包装」「发货数量」「批号」，按取数规则算出批号：
   - 有批号（含页面原有）→ 只看不发；
   - 需要填 → 点「批号」单元格 → 粘贴。
4. 填完整体截图复核一遍（数值、行对应关系、没有串行）。
5. 勾选**批号非空**的行：点序号列前的方框；批号为空的行不勾。
6. 点「确认发货」→ 弹窗「是否把选择的[N]明细执行发货操作?」→ **先核对 N 等于勾选行数** → 点「确定」。
7. 等刷新（2–5 秒）→ 重新点「查询」复查该院：
   - 若又有新数据出现 → 回到第 2 步继续填；
   - 直到「暂无数据」或只剩无法匹配的行 → 换下一家。
8. 分页栏保持「100条/页」。

## 四、常见陷阱

- 窗口不在前台时，键盘鼠标不会进入网页。脚本内置置前检查，失败会抛错；抛错就重新执行一次。
- 第一次点击常被「激活窗口」吃掉，点了没反应就再点一次（`-Times 2`）。
- 布局会上下浮动：每次操作前重新 `capture` 并定位，不要复用上一张截图的坐标。
- 「确认发货」按钮位置随页面滚动变化，提交前一定要截图确认 N 值正确。
- 不要点「撤销发货」「重置」「增加批次」「选择发票」，不要切换顶部页签或左侧菜单（用户明确只允许在「待发货」操作）。
- 若某些机构要求不同规则（例如只填不提交、按「今天 + 分公司代码 252/2521」筛表、网页发送时间选今天），按用户当次的说明执行，并把这些特例记进交付报告。

## 五、交付报告

全部处理完后，向用户汇报：

- 每家医疗机构：填写条数、提交结果（弹窗 N 值）、是否已复查为「暂无数据」；
- 跳过的机构，以及原因（用户指定 / 匹配不到数据）；
- 留空未填的行：流水号、品名、数量、原因；
- 只填未提交的机构单独列出。
