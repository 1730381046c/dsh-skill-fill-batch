# 填批号（Fill batch numbers）

一个 DSH bundle：把「填批号」这套流程做成可复用的技能，其他人在 DSH 里也能直接用。

安装后，模型技能目录里会出现 **`fill-batch-number`**（中文标题「填批号」）。给它两样东西即可：

1. 一份 **ERP 导出表**（`.XLS`，实际是 GBK 制表符文本；列名可为「发票日期」或「开单日期」）；
2. 一份 **要跳过的医疗机构名单**（可空）。

它就会在辽宁招采平台「按明细发货 → 待发货」页，按医疗机构逐家：筛选 → 对照品名/规格/数量取批号 → 填「批号」→ 勾选 → 确认发货 → 复查是否还有新数据，直到该院清空。

## 内容

| 文件 | 说明 |
|---|---|
| `assets/fill-batch/SKILL.md` | 技能正文：取数规则、网页操作步骤、陷阱、报告格式 |
| `assets/fill-batch/scripts/fillbatch.py` | 解析导出表；`dump` 全部行、`lookup` 按客户/品名查批号 |
| `assets/fill-batch/scripts/browser.ps1` | Windows 界面助手：PrintWindow 截图、置前、点击、剪贴板粘贴 |

## 使用

新开一个会话，直接说：

> 填批号，表格：`D:\...\批号26号.XLS`，跳过：大连市金州区第一人民医院

模型会加载 `fill-batch-number` 技能并按步骤执行。

## 限制

- Windows + 360 安全浏览器（或其他 Chromium 内核浏览器），本机已登录招采平台并停在「待发货」页。
- 网页控件无法用无障碍接口读取，只能靠截图定位点击；执行期间请勿手动操作浏览器。
- 只填「批号」列，不填有效期/备注，不点「撤销发货」。
- 匹配不到的品名会留空不提交，并在报告里列出，需要补导出表。
